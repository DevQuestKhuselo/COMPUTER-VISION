Computer Vision Notes

Personal notes on computer vision, written from scratch in HTML.

This repo is a two-birds-one-stone project: I'm learning computer vision, and using these notes as practice to get comfortable writing raw HTML (structure, semantics, styling, and eventually a bit of JS for interactivity).

Structure

Each chapter/topic lives in its own folder, with one or more .html files inside.

## 🏗️ Project Structure

```
COMPUTER-VISION/
├── CHAPTER 1/
|   ├── notes.html
|   ├── image pinhole.png
|   ├── lens image.png
|   ├── noimage pinhole.png
|   ├── pinhole.png
|
│
└── README.md

```

---
Folder names are numbered so chapters stay in order as the collection grows. Shared CSS lives in assets/ so individual note pages stay lightweight.

Goals
Build a solid, organized reference of CV concepts as I learn them
Practice semantic HTML, basic CSS layout, and (later) small interactive demos
Keep each chapter self-contained and readable as a standalone page
Viewing the notes

Open any notes.html file directly in a browser, or (optionally) enable GitHub Pages on this repo to browse them as a live site.

Status

Work in progress — chapters are added as topics are studied.
